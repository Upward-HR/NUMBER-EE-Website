# Employee Resource Portal

A professional, responsive static website for distributing employee resources, handbooks, benefits information, and essential documents.

## Features

- **Responsive Design** – Mobile-friendly layout with clean, accessible UI
- **Document Organization** – 21 approved documents organized into 4 categories:
  - HR & Company Policies
  - Payroll & Compensation
  - Benefits & Insurance
  - Workplace Tools & Resources
- **Easy Access** – Simple point-and-click document downloads
- **Professional Branding** – Forest green and gold color scheme with elegant typography

## Contents

- **index.html** – Main portal landing page
- **docs/** – All employee resource documents
- **assets/** – Additional resources (images, styles, etc.)

## Getting Started

1. Open `index.html` in a web browser
2. Browse documents by category
3. Click on any document to download or view
